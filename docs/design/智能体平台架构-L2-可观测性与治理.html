可观测性与治理 · 数据路径

埋点门面 Instrumentation（src/telemetry/tracing.py）
唯一入口：trace / guard / llm_call / tool_call。span 名与属性口径在此固化，业务代码不直接写属性
▼ span 属性（出口统一拦截）
出口脱敏 telemetry/redaction.py
凭据类（api_key/token/secret）直接丢弃；prompt 原文类键名保留、内容占位；PII 递归脱敏（身份证/手机号/银行卡）。不依赖调用方自觉
▼ TelemetryPort
OtelTelemetry（OTLP/HTTP）
BatchSpanProcessor 后台批量发送；导出失败不冒泡（观测挂了不拖垮业务）；进程退出时 shutdown 冲刷队列；缺 OTel 依赖自动回退 NoOp
▼ OTLP /v1/traces
Phoenix 自托管（D4 · v20）
端口 6006 · SQLite 单文件 · 数据卷 shared/data/phoenix（与 releases 分离，回退不丢 trace）· healthz 冒烟检查
▼ GraphQL 查询
指标汇总 phoenix_metrics.py
Q/P/C/S 四组（质量/性能/成本/安全），口径见 docs/metrics.md；CLI 可脚本化、可进 CI；含分页防静默截断
审计账本 AuditLedger（append-only）
JSONL @ shared/audit/ledger.jsonl · 保留 365 天 · 原子重写清理 · 单进程独占。每条判定记 request_id / tenant / use_case / stage / action / rule / evidence（落盘前已脱敏）
